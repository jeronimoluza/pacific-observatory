## 2026-09-11 (onboard4 shard) — Bank Indonesia PIHPS onboarded

- **Bank Indonesia PIHPS Nasional** — https://www.bi.go.id/hargapangan/TabelHarga/PasarTradisionalDaerah — **SHIPPED as `bi_pihps`** (fetcher, `rest_api`, `official_avg`). Indonesia's first `official_avg` source: the daily strategic-food price survey, national average, traditional markets, 21 commodities, history back to mid-2017. The page is a DevExtreme (DevExpress ASP.NET MVC) grid whose backing routes are unauthenticated JSON and answer cold to plain `requests` — no session, no key, no WAF, no Playwright. Two things cost time and are worth recording: (1) the sibling *Komoditas* view and its `GetGridDataKomoditas` route return an empty `data` array for every report type and date range tried — `GetGridDataDaerah` with the province/regency/market filters left **blank** is the route that yields the national series; (2) the grid is WIDE (one row per commodity, one column per date keyed `DD/MM/YYYY`) and mixes `level: 1` category aggregates with `level: 2` commodities, so emitting both double-counts. Same host also exposes Pasar Modern / Pedagang Besar / Produsen via `price_type_id` 2/3/4 — three more sources for free, not built this pass.
